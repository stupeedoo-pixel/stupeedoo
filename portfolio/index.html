About

I'm a self-taught developer who likes the part of the job where design and code meet. Most of what I build starts as a single HTML file and grows from there — no framework until the project earns one.

I care about typography, motion that has a reason to exist, and pages that work on a phone as well as they do on a laptop. Lately I've been building small, self-contained sites: an art gallery, an interactive card, and this portfolio.

Currently open to freelance work, internships, and collaborations. If you've got something you'd like built, I'd like to hear about it.
